# Koeiro v0.13.5: 拍手やキーボードの音を「そのまま」届ける環境音パススルーと、実測した GPU（CUDA）経路

## 🌟 ハイライト

* **環境音パススルーを追加しました。** 拍手・キーボード・物音などの一過性の環境音を、
  モデルを通さずそのままリスナーへ届けます。声はこれまでどおり変換され、声が戻ると
  すぐに通常の変換へ戻ります。逐次変換・一括変換の両方で動き、既定は ON です。
  設定の「環境音をそのまま通す」でいつでもオフにできます。
* **咳・鼻すすり・くしゃみは変換します。** これらは環境音とみなさず、生の声が漏れない
  側（fail-closed）で扱います。
* **GPU（CUDA）経路を実測つきで有効にしました。** Kaggle の Tesla T4 で CPU 経路と
  -67〜-76 dB まで一致（float32 の丸め差）し、2.0〜2.7 倍速。cpu/cuda のペアを再生しての
  聴き比べも実施済みです。「自動」は実測済みの MeanVC2 だけ GPU を使い、CPU に固定したい
  ときは「CPU」を選んでください。
* **「一括-高品質」を追加しました。** 上流 CLI と同じ全体補間・ノイズで条件付けし、
  ソルバーステップを増やした品質ルートです（通常の一括変換より変換に時間がかかります。
  採用は聴き比べで判断します）。
* **Issue #6 の2件を修正しました。** モニター出力が出力専用デバイスで開けない問題と、
  GPU 指定時の AI 起動失敗です（詳細は下）。

## 🛠 追加・修正

### 環境音パススルー（新機能）

* **逐次変換**: callback 安全な位置合わせリングと、Silero VAD・YAMNet・transient 検知の
  ゲートで、変換出力の対応区間だけを生の入力に差し替えます。
* **一括変換**: 発話ごとの変換結果に対し、イベント区間だけ生サンプルを差し込みます
  （継ぎ目は 1.3 ms のクロスフェードのみ）。発話の間の環境音は、変換を待たずイベント
  部分だけが先に届きます。
* 「最速」では短い物音が「ノイズ」として捨てられることがありましたが、その区間も
  ゲートに回して救済します。
* ゲートの計算は変換と並行に走り、無音区間ではモデルを動かしません（実測: 30 秒の
  ほぼ無音＋1 イベントで 2.2 秒 → 0.6 秒）。会話のテンポと RTF への影響を抑えています。
* 診断画面に、変換内で生のまま通した秒数と、発話の間から届いた秒数を表示します。

### GPU（CUDA）（Issue #6 の②）

* トレース（fastu2pp）に焼き込まれた CPU の device 定数を、実行デバイスへ書き換えます
  （報告いただいた `found at least two devices` の原因）。
* CUDA graph capture で ASR/VC の段を再生します。
* 「自動」は実測済みバックエンド（MeanVC2）のみ GPU を選びます。実行デバイス上で動かせ
  なかった場合は「CPU」への切り替えを案内します（「自動」では再び CUDA を選ぶため
  案内しません）。

### モニター出力（Issue #6 の①）

* モニターのテスト音・再生が入出力共用のストリームで開いていたため、出力専用デバイス
  （USB DAC 等）で `Invalid number of channels` になっていました（macOS でも同症状の
  報告あり）。出力専用（OutputStream）で開くよう修正しました。

### 一括-高品質（実験）

* `quality` ルートと「一括-高品質」プリセットを追加しました。offline 変換では抑揚補正を
  全 hop に適用します（逐次はリアルタイム性のため、間に合わない補正をバイパスする既存の
  仕様のままです）。

### その他の修正

* 声の登録の watchdog を「無応答 15 分 / 絶対 4 時間」に緩和しました（長い素材の登録が
  途中で止まらないように）。
* コントリビューション #5（TKY-27 さん）の2件を取り込みました: AI 設定のロード後に
  実行デバイスや音声調整（tune_*）を変えても古い起動引数のままだった問題（ロード済み
  ワーカーを再起動して反映します）と、POSIX で TTS 専用 venv から外れてしまう問題です。
* リリース用: 非音声ゲートのモデル3点（Silero VAD・YAMNet・class map）を配布物に同梱
  します（取得できなくても変換は止まらず、パススルーが無効になるだけです）。

## ⚠️ 既知の制限

* **この版でも実機の通話・配信での確認はしていません。** マイク・出力を使った変換、
  Discord 経由の確認、環境音パススルーの実聴評価は未実施です（検証は保存 WAV を通した
  オフラインの数値までです）。
* GPU の動作確認は Kaggle の Tesla T4 です。お手元の GPU 実機での確認は環境によっては
  失敗することがあります（その場合は「CPU」へ切り替えてください）。
* Linux の RTF はこの版でも申告できる値を持っていません（コンテナ内の計測のみ）。
* 声の登録は凍結ビルドでは出来ません（従来どおり）。
* `setup.exe` と Linux の凍結ビルドに Authenticode / GPG 署名は入れていません。
  sha256 は破損・途中切れの検知です。
* 実行ファイル版の自動更新は GitHub Releases を見にいくので、ネットワークが必要です。

## ✅ この版で実測したこと

* テスト一式: **1329 passed / 14 skipped**（skip は環境依存のみ）。回帰テストには、
  オフラインゲートの生声 veto（先頭フレームの見落とし）、起動パラメータ変更での
  ワーカー再起動、環境音ルーティングのブリッジ動作などが含まれます。
* 環境音パススルーのオフライン検証（実モデル MeanVC2 + LavaSR、音声デバイス無し、
  `tools/verify_env_passthrough_offline.py`）:
  * 実録音（拍手・ノック・タイピング）: ルーティングした 4 区間中 3 区間が
    **誤差 0.0 のビット一致**で生出力（残り 1 区間はキュー競合で fail-closed に破棄）。
  * 音声を重ねた合成入力: ルーティング 2/2 がビット一致、**音声の生漏れなし**。
* CUDA: Kaggle T4 で CPU と -67〜-76 dB 一致・2.0〜2.7 倍速
  （`notes/kaggle_gpu_verification.md`）。
* 配布物（Windows の setup.exe・AIパック、Linux の凍結バンドル・AIパック、ソースツリー）は
  `release` ワークフローが作り、添付前の検査（`tools/verify_release_assets.py`）を通してから
  添付します。
